# Release 0.1.31 — collapse leftover lists

Keep the garden's existing bones and cut the copies: one lens-order list, one theme drawer, first paint that agrees with React, and Plant Here that sees the live bed height.

## Highlights

- Makes `LENS_KINDS` the only lens-order list. Domain, validation, and garden layout read it instead of copying the seven kinds.
- Writes theme only through settings JSON. The leftover `theme-preference` key migrates on read and is deleted after a successful write, so a corrupt leftover can no longer wipe a good setting.
- Paints first theme from the same load path as runtime. A valid leftover still wins. Settings is used only when React would accept the object. An incomplete `{ themePreference: 'dark' }` falls through to system.
- Shrinks `GardenState` to `{ seeds }`. The synthesized pet mood object was never read by Phaser.
- Drops a lens session in one place, maps seed status through one growth table, and removes `writeRaw` with the leftover theme writer.
- Gives Plant Here the live canvas width and height. Desktop plots interpolate from the cover-crop, so a height of 0 was storing the wide-anchor point.

## Lore

Constraint: The garden already had layers. The review could cut copies and close storage seams, but it could not pour EventBus, Redux, or a new folder tree.
Rejected: Add an EventBus for five Phaser callbacks | Official Phaser React templates use one for scene-ready. These callbacks are 1:1 and already typed; a bus would add a layer without deleting a present cost.
Rejected: Read settings theme before a valid leftover key | Runtime still lets a valid leftover win. First paint has to match that, or a migrate-only key and the painted theme disagree.
Rejected: Trust `themePreference` on an object React would reject | `{ themePreference: 'dark' }` without `reducedMotion` is not settings. Runtime uses system. First paint must do the same.
Rejected: Split `gardenLayout.ts` or `PetController.ts` | Those files are placement tables and one state machine, not leftover god classes.
