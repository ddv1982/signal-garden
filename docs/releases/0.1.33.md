# Release 0.1.33

Keep reflections safe through interrupted saves and concurrent tabs, and save completed journeys to Archive when the garden is full.

## Highlights

- Save completed reflections directly to Archive without a plot. Revisit original answers, dates, watering records and bloom reflections.
- Preserve reflections when saves fail or browser storage is full. Recovery export remains available, and failed reads keep open forms and their answers visible.
- Coordinate saves across tabs so stale edits cannot overwrite newer answers or restore deleted seeds.
- Save unfinished answers as you type, with a visible saved state and explicit conflict handling.
- Include pending reflections in export and deletion. Deleting completed reflections preserves an unfinished journey.
- Keep all twelve garden plots visible and selectable on mobile. Fix plot taps intercepted by the companion or pending seed, and resize the canvas from its container dimensions.
- Apply either the app or operating-system reduced-motion preference to both interface and garden animations.
- Support PNG and WebP in asset maintenance tools, with copied-fixture checks in CI. Committed source art is unchanged.

## Reliability and accessibility

Reflection data now lives in one versioned document. Migration validates the destination and commits it before removing legacy keys; malformed originals remain available for recovery. Garden keyboard controls match visible planted reflections, and pending reflection tabs skip unavailable care controls.

## Verification

The implementation passed 148 unit tests, 142 desktop/mobile browser tests, two asset-fixture tests, typechecking, lint, formatting, art provenance and production build checks. Independent review and matched performance probes covered save recovery, concurrent tabs, retained drafts, Archive history, mobile interactions and reduced motion.

## Compatibility notes

Reflection saves require Web Locks on HTTPS or localhost. Unsupported environments retain viewing and export access. Wait for the saved indicator before closing a journey; text whose save has not finished can still be lost if the browser closes. Reload older open tabs after updating so they use the new reflection document.

Export version 1 remains compatible through an additive optional placement field. Reflection text stays local to the browser.
